# Purifiers - Modern Product Showcase & E-Commerce Landing Page

A sleek, fully responsive premium landing page designed for a modern air purifier brand. This project demonstrates high-end UI/UX layout execution, interactive product components, and clean conversion-focused frontend architecture.

## 🚀 Live Demo
[👉 Click here to view the live website](https://romarios144.github.io/Purifiers/)

## 🛠️ Tech Stack & Tools
* **Core:** HTML5, CSS3 / SCSS (Structured, maintainable layout approach)
* **Scripting:** JavaScript (ES6+) for UI interactions
* **Design Implementation:** High-fidelity responsive translation from design to code

## 📦 Key Features
* **Product Carousel / Slider:** Smooth, touch-responsive slider implementation to showcase various product models or features.
* **Modern Minimalist UI:** Clean aesthetic with sharp typography and subtle hover animations tailored to premium consumer tech industries.
* **Conversion-Oriented Blocks:** Structured presentation including product benefits, technical specifications, and clear Call-to-Action (CTA) sections.
* **Fluid Responsiveness:** Fully optimized grid/flexbox layout ensuring seamless performance across Mobile, Tablet, and Desktop viewports.

## ⚙️ How to Run Locally
1. Clone or download the repository.
2. Open the `index.html` file directly in any modern web browser, or use a local development extension like *Live Server* in VS Code.
